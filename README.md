
# 💸 App de Organização de Finanças Pessoais do Marcos com Vibe Coding  
Este projeto foi criado como parte de um desafio da DIO sobre Vibe Coding, usando as ferramentas Lovable e Copilot Web. A ideia é desenvolver um aplicativo que ajude as pessoas a organizar suas finanças pessoais de forma simples, usando conversas em linguagem natural, como se estivesse falando com alguém.

## 📑 PRD – Aplicativo de Finanças Conversacionais  

---

### 1. Contexto do Projeto  
**Descrição:**  
O app será um assistente financeiro conversacional, permitindo que o usuário organize suas finanças por meio de chat.  

**Exemplo prático:**  
Usuário digita: “Gastei R$ 50 no mercado ontem”  
→ O app registra automaticamente a despesa, sem precisar preencher formulário.  

---

### 2. Problema a ser Resolvido  
**Descrição:**  
Apps atuais exigem muito esforço manual e não oferecem personalização.  

**Exemplo prático:**  
- App tradicional: usuário precisa abrir tela de “Nova despesa”, escolher categoria, digitar valor, data, descrição.  
- Novo app: basta escrever “Paguei R$ 120 no Uber” → o sistema entende que é transporte e classifica sozinho.  

---

### 3. Público-Alvo  
**Descrição:**  
Pessoas que querem começar a organizar suas finanças de forma simples.  

**Exemplo prático:**  
- Estudante universitário que nunca usou planilhas.  
- Jovem profissional que quer controlar gastos sem perder tempo.  
- Usuário iniciante que prefere conversar com o app em vez de aprender menus complexos.  

---

### 4. Funcionalidades Principais  
**Descrição:**  
Lista das funções essenciais do produto.  

**Exemplo prático:**  
- Registro por chat: “Recebi meu salário de R$ 2.500” → app registra como receita.  
- Classificação automática: “Comprei pizza por R$ 40” → app classifica como alimentação.  
- Metas financeiras: usuário define “Quero economizar R$ 300 este mês” → app acompanha progresso.  
- Agente Financeiro: envia mensagem: “Você gastou 20% a mais em transporte este mês, que tal usar mais transporte público?”  
- Relatórios: gráfico simples mostrando gastos por categoria (alimentação, transporte, lazer).  

---

### 5. MVP – Entregas Esperadas  

#### Principais Telas  
- **Tela de Chat:** interface principal para registrar e conversar.  
  *Exemplo:* caixa de texto + histórico de mensagens.  
- **Tela de Metas:** lista de metas criadas pelo usuário.  
  *Exemplo:* “Economizar R$ 300 em janeiro” com barra de progresso.  
- **Tela de Relatórios:** gráficos simples.  
  *Exemplo:* pizza chart mostrando 40% alimentação, 30% transporte, 30% lazer.  

#### Funcionalidades Essenciais  
- Registro de transações por chat.  
- Classificação automática de gastos.  
- Definição de metas básicas.  
- Relatórios simples.  
*Exemplo:* MVP não precisa ter exportação para Excel ou relatórios avançados, apenas gráficos básicos.  

#### Recursos Técnicos Necessários  
- NLP (Processamento de Linguagem Natural): para entender frases como “gastei no mercado”.  
- Banco de Dados: para guardar transações.  
- Algoritmos de categorização: para classificar automaticamente.  
- Módulo de relatórios: para gerar gráficos.  
*Exemplo:* usar uma biblioteca de gráficos simples como Chart.js ou D3.js.  

#### Validação Inicial  
- Testar com 10 usuários iniciantes.  
- Coletar feedback: “Foi fácil registrar despesas?”, “Os relatórios ajudaram?”.  
- Ajustar pontos críticos antes de expandir.  
*Exemplo:* se os usuários acharem difícil escrever frases, incluir sugestões automáticas como botões rápidos (“Registrar gasto”, “Definir meta”).

### 📌 Resumo do App  
O aplicativo é uma ferramenta de organização de finanças pessoais feita por conversa.  
Em vez de usar planilhas ou formulários complicados, o usuário fala com o app como se estivesse conversando com alguém.  

Por meio do chat, a pessoa consegue:  
- Registrar gastos e receitas  
- Entender melhor para onde o dinheiro está indo  
- Receber dicas simples para economizar  
- Acompanhar sua vida financeira de forma mais leve e prática  

A ideia principal é facilitar o controle financeiro, principalmente para quem está começando e sente dificuldade com aplicativos tradicionais.  

---

### 💡 Reflexão sobre o Processo  

#### ✅ O que funcionou bem  
> O que funcionou melhor foi a ideia de usar conversa em vez de telas cheias de campos.  
Isso torna o uso mais simples e menos cansativo.  
Também funcionou bem o uso da inteligência artificial para ajudar a pensar no app, organizar as ideias e criar algo funcional de forma rápida.  
Além disso, ficou claro que dá para criar um projeto interessante mesmo sem saber tudo de programação.  

#### ⚠️ O que não funcionou como o esperado  
> Algumas respostas da IA nem sempre ficaram exatamente do jeito imaginado, exigindo ajustes e novas tentativas.  
Também foi um desafio deixar tudo realmente simples, pois às vezes a tecnologia tende a complicar demais as coisas.  
Outro ponto foi perceber que, mesmo com ajuda da IA, é preciso ter clareza no que se pede, senão o resultado pode fugir da ideia inicial.  

#### 📖 O que aprendeu sobre conversar com IAs  
> Aprendi que conversar com uma IA é parecido com conversar com uma pessoa:  
- Quanto mais claro você explica, melhor é a resposta  
- Ajustar o pedido faz muita diferença no resultado  
- A IA ajuda muito, mas não substitui o pensamento humano  
- Também percebi que a IA é uma grande aliada para aprender, testar ideias e criar projetos, principalmente para quem está começando.
